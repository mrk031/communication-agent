## 2026-10-06：真实数据与检索 Baseline 准备完成

- 从服务器只读导出 2 份《通信原理》教材原文、3,794 个 RAGFlow Chunk、52 条教师答疑；清洗后教师答疑可用 51 条。
- 明确教师答疑原链路是 Elasticsearch 案例命中并单独展示，不属于 SFT，也没有作为 LLM 的 RAG 上下文。
- 冻结当前 RAGFlow Baseline：`text-embedding-3-large`、Top-K 4、阈值 0.2、向量权重 0.3、关键词权重 0.7、无 rerank、无 GraphRAG。
- 离线 BM25 代理 Baseline：51 题，Top-4，问题覆盖率 48.11%，教师答案覆盖率 35.37%，检索 P50/P95 为 94.8/167.3 ms，平均上下文约 510 字符。
- 定位真实向量检索失败原因为查询 Embedding 服务余额不足，而非历史向量或 RAGFlow API Key 损坏；更新模型供应商配置后，RAGFlow 页面检索恢复。
- 评测设计采用三级数据：人工审核 Gold、自动生成 Silver、教师答疑困难集；教师答疑不作为教材检索能力的唯一正式评测集。

## 2026-10-06：自动评测集生成链路建立

- 新增 `generate_eval_questions.py`：读取本地 Chunk 副本，组合相邻短 Chunk，按教材与章节分层抽样。
- 每个证据窗口生成贴近原文问题、口语改写问题、参考答案、逐字证据和 Gold Chunk ID。
- 自动拦截证据不在原文、Chunk ID 非法、字段缺失、问题未改写、疑似照抄和重复问题。
- 支持 dry-run、断点续跑、失败重试、JSON 模式开关；模型接口和密钥只通过本地配置传入。
- 首次真实 Chunk dry-run 发现参考文献块和超长单块会污染抽样，随后增加参考文献/目录识别和严格窗口上限；体现了先审证据质量、再付费生成的调试策略。
- 下一节点：生成约 300 条 Silver 候选，人工审核约 60～100 条形成 Gold V0，并运行真实 RAGFlow Recall@K/MRR Baseline。

## 2026-10-06：真实 RAGFlow Gold-dev Baseline 完成与诊断

- 本地评测器通过配置的 RAGFlow `/api/v1/retrieval` 接口调用服务；返回记录包含 dataset/document ID、混合分数、向量分数和关键词分数，确认不是离线 BM25。
- 原始60题结果：Hit@1 70.0%、Hit/Recall@4 85.0%、Hit/Recall@10 90.0%、MRR 0.770、nDCG@4 0.785。
- 性能：P50 1.290s、P95 1.787s；首请求8.220s，为明显冷启动/异常长尾，排除首请求后平均约1.367s。
- Top-4漏召回9题：3题实际位于第5～10名，6题未进入Top-10；说明单纯把Top-K从4增到10最多只直接补回5个百分点，同时增加上下文成本。
- 发现1道“教材版本改动”题属于评测数据污染且无检索结果，已完善规则并替换。旧结果与修订后Gold-dev重合59/60；这份结果可用于诊断，正式e00需重跑修订后的60题。
- 排除该污染题后的59题诊断值：Hit@1 71.2%、Hit@4 86.4%、Hit@10 91.5%、MRR 0.784、nDCG@4 0.798。
- 利用服务器返回的Top-10向量/关键词子分数进行候选池内重排：向量权重0.4估算Hit@1 74.6%、MRR 0.803；权重0.6估算Hit@4 91.5%、MRR 0.806。由于候选池由原权重0.3产生，这只是筛选后续线上实验点的近似结果。
- 阈值0.2以上的离线截断分析明显恶化：0.25时Hit@4约79.7%，0.3时约66.1%；下一轮不提高阈值，重点实测0.1与0.2。
- 下一轮最小实验矩阵：修订版e00（w=0.3,t=0.2）、e01（w=0.4,t=0.2）、e02（w=0.6,t=0.2）、e03（w=0.4,t=0.1）；先固定Top-4，无rerank。

## 2026-10-07：混合检索权重与阈值消融完成

- e03（vector=0.4, threshold=0.1）与e01的Top-10排序及全部正式指标完全一致；降低阈值只让所有题都返回满10个候选，没有带来召回收益，因此保持0.2。

- e02剩余4个Top-4失败：2个Gold位于第6/7名，适合用rerank验证；2个未进入Top-10，需测试更大候选池、相邻Chunk扩展或查询改写。

- 下一节点：在dev上固定threshold=0.2、vector weight=0.6，比较candidate Top-10/20后rerank到Top-4，或先构建无需额外模型的邻接扩展实验；test仍保持未使用。
